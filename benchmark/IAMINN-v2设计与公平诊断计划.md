# IAMINN-v2 设计与公平诊断计划

## 1. 设计目标
IAMINN-v2 的目标不是继续在 IAMINN-v1 上微调，而是针对 v1 的结构性失败重新设计：
- 避免材料场塌缩为常数场
- 避免状态分支绕开材料分支
- 提升界面识别能力
- 保持实验公平、结果真实

## 2. v2 的核心结构
### 2.1 与 v1 的核心区别
IAMINN-v2 不再让网络直接输出应力场，而是：
1. `state_net` 只输出位移 `ux, uy`
2. `interface_net` 负责输出界面相关表示
3. 材料参数由少量区域参数和界面掩码组合得到
4. 应力不再直接由网络自由输出，而是由 `u + lambda + mu` 通过本构关系显式计算

这样做的核心目的是：
- 让材料场必须真正参与力学平衡
- 避免 v1 中状态分支“自己把应力和位移都拟合完”的问题

### 2.2 layered / single_inclusion 的界面表示
对于 `layered` 和 `single_inclusion`：
- 采用单标量界面指示量
- 再通过 sigmoid 得到区域概率
- 材料参数由背景区域和目标区域两套参数混合得到

### 2.3 double_inclusion 的处理
为了兼容 `double_inclusion`：
- 预留多区域概率扩展
- 当前第一轮公平诊断先聚焦 `layered`
- 不在代码中假装已经完成 double_inclusion 的正式方法论验证

## 3. 为什么 v2 比 v1 更合理
### 3.1 耦合更强
v2 中应力由位移和材料参数共同决定，因此：
- 材料场错误会直接影响平衡残差
- 网络更难靠“自由输出应力”绕过材料识别

### 3.2 更符合 inverse mechanics 的目标
当前任务本质是材料识别，不是单纯拟合应力图。因此：
- 让应力作为显式物理推导结果
- 比直接回归应力更符合任务本质

### 3.3 更接近“界面识别 + 区域参数识别”
v2 更像是在做：
- 界面在哪
- 每个区域材料是多少

而不是在整个平面上自由回归一个材料场函数。

## 4. 第一轮公平诊断设置
### 4.1 诊断目标
先验证一个最小但严格的问题：
- `layered`
- `PINN` vs `IAMINN-v2`
- 看 v2 是否已经在材料识别上优于 PINN

### 4.2 公平性要求
第一轮诊断仍然保持：
- 同一个二维方板
- 同一个 `layered` case
- 同一个 soft boundary 设定
- 同一个观测点缓存文件
- 同一个 optimizer family
- 同一个 seed
- 同一个训练点数和观测点数
- 同一个验证集选模规则

### 4.3 诊断规模
为了先判断方向是否成立，第一轮只做小规模诊断：
- `iterations = 5000` 或 `10000`
- 只做 `layered`
- 如果 v2 连 `layered` 都赢不了 PINN，就不值得直接开 `50000`

### 4.4 成功判据
只有同时满足以下条件，才值得继续：
1. `lambda` 误差优于 PINN
2. `mu` 误差优于 PINN
3. 材料场向量误差优于 PINN
4. 观测点 MSE 不明显劣化
5. 不只是 PDE residual 好看，而是逆问题主指标也更好

## 5. 失败判据
如果出现以下任一情况，则 v2 暂不进入正式 50000 步实验：
1. 材料场仍然塌成近似常数
2. `lambda/mu` 误差没有优于 PINN
3. 只是 PDE residual 更低，但 observation / material metrics 没提升
4. 结构更复杂但稳定性更差

## 6. 第一轮要额外保存的结果
为保证后续论文写作和失败诊断，v2 的实验结果应至少保存：
- `json/`：完整配置、训练摘要、训练集/验证集/评估集元数据、界面参数摘要
- `metrics/`：每个 split 的 metrics json 与 txt
- `npz/`：train/validation/evaluation 数据、稠密网格预测、界面诊断结果
- `txt/`：各 split 明细表、观测拟合结果、材料区域参数
- `png/`：损失曲线、所有损失项、场对比图、材料图、界面诊断图、采样图
- `dat/`：loss history.dat
- `model/`：best 与 last checkpoint

## 7. 进入正式实验的前提
只有在 small diagnostic 中确认 IAMINN-v2 优于 PINN 后，才进入：
- `50000` 步正式实验
- `single_inclusion`
- 之后再考虑噪声、观测点数量、消融等实验

## 8. 当前阶段结论
当前阶段的正确策略不是扩展更多 case，而是：
1. 用最小公平诊断验证 v2 是否真正有效
2. 只在 layered 胜出后才继续增加算力和实验规模
3. 保持所有结论基于真实结果，而不是基于主观期待
