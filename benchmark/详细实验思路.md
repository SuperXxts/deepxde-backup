# 空间变化材料参数识别详细实验思路

## 1. 研究目标与当前定位

我们的目标不是把现有的常数参数反演脚本继续堆案例，而是把问题升级为：

1. 在二维线弹性小变形框架下，识别空间变化的材料参数场 `lambda(x,y)` 和 `mu(x,y)`。
2. 在统一训练预算、统一采样、统一评价指标下，比较：
   - `PINN`：单网络同时预测状态场和材料场。
   - `PI-MINN`：状态场网络 + 材料场网络，通过物理约束耦合训练。
3. 在真实保存全部训练过程的前提下，输出可复现、可统计、可用于论文的结果。

当前阶段的定位：

- 第一阶段先使用 `manufactured solution`（构造真解）把代码、损失、评估、可视化、目录规范全部跑通。
- 第二阶段再补 FEM 数据。
- 这不是作弊，而是标准 benchmark 建设流程。文中必须明确说明真值来源。

## 2. 为什么先做构造真解，再做 FEM

| 方案 | 当前是否采用 | 用途 | 说明 |
|---|---|---|---|
| 构造真解 | 是 | 第一阶段 benchmark | 最适合验证方法、调通训练管线、做损失与可视化分析 |
| FEM 数据 | 下一阶段必须补 | 主论文主结果 | 更接近真实工程数据，更适合顶刊结论 |
| DDA 数据 | 暂不作为第一阶段主线 | 后续扩展 | 更复杂，先把连续体问题做扎实再接 |

当前没有现成商业 FEM 软件，不代表无法做 FEM。下一阶段建议优先使用纯 Python 路线：

1. `scikit-fem` 生成二维线弹性正演真值。
2. 统一导出为 `npz` 数据文件。
3. 保持与当前 benchmark 相同的训练 / 评估接口。

## 3. 问题定义

求解域为单位方板：

- 几何域：`[0, 1] x [0, 1]`
- 物理：二维线弹性、小变形
- 观测：域内稀疏位移观测点
- 目标：恢复
  - 位移场 `ux, uy`
  - 应力场 `sxx, syy, sxy`
  - 材料参数场 `lambda(x,y), mu(x,y)`

当前已实现 3 类材料场：

| case | 含义 | 用途 |
|---|---|---|
| `layered` | 分层材料 | 最简单的空间材料场任务 |
| `single_inclusion` | 单夹杂材料 | 第一主实验 |
| `double_inclusion` | 双夹杂材料 | 更复杂验证 |

说明：

- 当前材料场界面是平滑过渡，而不是严格数学阶跃界面。
- 这是因为强形式 PINN 对不可导界面更敏感，第一阶段先用平滑界面是合理的。

## 4. 方法定义

### 4.1 PINN 基线

单网络同时预测：

- `ux, uy, sxx, syy, sxy, lambda, mu`

### 4.2 PI-MINN

`PI-MINN` 的含义是：`Physics-Informed Material Identification Neural Network`。

结构拆分为：

1. 状态场网络：
   - 输出 `ux, uy, sxx, syy, sxy`
2. 材料场网络：
   - 输出 `lambda(x,y), mu(x,y)`
3. 两个网络通过 PDE 残差与观测误差联合训练。

### 4.3 目前不把 DeepONet 作为主基线的原因

当前问题仍然是“一个具体 inverse problem 的求解器”，不是“学习从工况函数到解场的 operator”。因此：

- 主基线应当是 `PINN`。
- `DeepONet / PI-DeepONet` 可以作为下一阶段多样本、多工况扩展时的补充基线，但不是当前第一阶段主对比。

## 5. 训练范式选择

| 训练范式 | 是否推荐作为主方案 | 原因 |
|---|---|---|
| 纯物理驱动 | 不推荐 | 空间参数场反演欠约束，容易不稳定 |
| 纯数据驱动 | 不推荐 | 物理可信度不够，工程说服力弱 |
| 物理 + 数据驱动 | 推荐 | 最符合 inverse solid mechanics 问题本质 |

因此主方案固定为：

- `physics loss + sparse observation loss + material regularization`

## 6. 损失函数设计

总损失：

`L = L_physics + L_obs + L_reg`

更细地写为：

`L = L_momentum + L_constitutive + L_obs + L_reg`

当前实现中具体包括：

| 损失项 | 含义 | 是否必须 |
|---|---|---|
| `momentum_x, momentum_y` | 动量守恒残差 | 必须 |
| `constitutive_xx, constitutive_yy, constitutive_xy` | 本构关系残差 | 必须 |
| `obs_ux, obs_uy` | 观测位移误差 | 必须 |
| `lambda_x, lambda_y, mu_x, mu_y` | 材料场平滑正则 | 推荐 |

其他处理：

| 设计 | 当前是否采用 | 作用 |
|---|---|---|
| `softplus` 正值约束 | 是 | 保证 `lambda, mu > 0` |
| 边界位移输出变换 | 是 | 通过输出变换自然满足零边界位移 |
| Fourier features | 是，可消融 | 提升空间高频表达能力 |

## 7. 公平比较原则

所有方法必须使用同一套设置：

1. 相同的几何域。
2. 相同的 case 定义。
3. 相同的观测点数量。
4. 相同的噪声水平。
5. 相同的训练配点数量。
6. 相同的测试网格。
7. 相同的随机种子集合。
8. 相同的训练预算（迭代数、学习率）。

不能做的事情：

1. 不能只给某个方法更多训练点。
2. 不能只给某个方法更多迭代数。
3. 不能只汇报最好的一次，不汇报 seed 稳定性。
4. 不能对失败实验手动删结果后只保留好看的结果。

## 8. 统一评价指标

所有方法统一使用相同指标。

### 8.1 核心指标

| 指标类别 | 指标 | 说明 |
|---|---|---|
| 材料场误差 | `lambda` relative L2 | 核心指标 |
| 材料场误差 | `mu` relative L2 | 核心指标 |
| 位移场误差 | `ux, uy` relative L2 | 反映场恢复质量 |
| 应力场误差 | `sxx, syy, sxy` relative L2 | 反映物理场一致性 |
| 观测拟合 | `observation_mse` | 反映观测点拟合程度 |
| 物理一致性 | `pde_residual_mean_abs` | 反映是否真正满足 PDE |
| 点误差 | `field_mae` | 更直观 |
| 效率 | 训练时间 | 反映算力成本 |
| 模型复杂度 | `parameter_count` | 反映模型开销 |

### 8.2 为什么必须统一指标

原因很简单：

- 如果不同方法用不同指标，结论不公平。
- 如果只看观测点误差，不看 PDE 残差，可能只是把观测点记住了。
- 如果只看场误差，不看训练时间，方法可能不具备工程价值。
