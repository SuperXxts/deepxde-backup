# 空间变化材料参数识别详细实验思路

## 1. 当前状态

上一版双网络方法及其变体已经从当前研究主线中移除，原因很简单：

1. 它在真实对比实验中没有稳定优于 `PINN`。
2. 它的材料场识别效果没有形成足够有说服力的提升。
3. 继续在这条线上调超参数，性价比很低。

因此，当前仓库中保留的是：

- `PINN` baseline
- benchmark 数据生成、训练、评估、可视化流程
- 为新方法预留的实验框架

当前不再把上一版双网络方法作为论文候选方法。

## 2. 研究目标

新的主目标是：

1. 在二维线弹性小变形框架下，识别空间变化的材料参数。
2. 不再把材料场当成任意平滑函数直接回归。
3. 将问题改写为“界面感知的材料识别问题”。
4. 在统一预算、统一采样、统一指标下，与 `PINN` baseline 做公平比较。

## 3. 为什么要从平滑材料场回归，转向界面感知识别

我们当前的典型任务：

- `layered`
- `single_inclusion`
- `double_inclusion`

它们都有一个共同特点：

- 真实材料分布不是“任意连续起伏”
- 而是“背景材料 + 一个或多个区域材料”
- 本质上更接近“界面/分区识别”

如果仍然让网络直接学习：

- `lambda(x, y)`
- `mu(x, y)`

那么网络会把问题当成一般函数拟合。这样会带来三个问题：

1. 搜索空间过大
2. 容易把界面抹平
3. 容易出现“损失下降了，但材料场没识别对”的情况

这和我们已经观察到的失败现象是一致的。

## 4. 方向 A：界面感知材料识别

### 4.1 核心思想

不再直接预测完整材料场，而是拆成：

1. `state net`
   - 输入：`(x, y)`
   - 输出：`ux, uy, sxx, syy, sxy`

2. `interface net`
   - 输入：`(x, y)`
   - 输出：`phi(x, y)`
   - 含义：点位于背景区域还是夹杂区域的隐式表示

3. `material scalars`
   - `lambda_bg, mu_bg`
   - `lambda_inc, mu_inc`

4. 通过 `phi(x, y)` 构造空间材料场

### 4.2 最简单的参数化方式

对于单夹杂任务，可设：

- `m(x, y) = sigmoid(alpha * phi(x, y))`
- `lambda(x, y) = lambda_bg + m(x, y) * (lambda_inc - lambda_bg)`
- `mu(x, y) = mu_bg + m(x, y) * (mu_inc - mu_bg)`

其中：

- `m(x, y)` 接近 `0` 表示背景材料
- `m(x, y)` 接近 `1` 表示夹杂材料
- `alpha` 是界面锐化系数，可逐步增大

这样做以后：

- 材料场不再是任意自由函数
- 而是“分区 + 少量参数”的结构化表达

### 4.3 对不同 case 的扩展

#### `layered`

可以直接用一条界面：

- `phi(x, y)` 决定上层/下层

#### `single_inclusion`

可以继续用单个 `phi(x, y)`：

- 背景区域 vs 单夹杂区域

#### `double_inclusion`

有两种方案：

1. 两个 `phi`
   - `phi1(x, y)`
   - `phi2(x, y)`
2. 一个多类 `mask net`
   - 输出背景/夹杂1/夹杂2 的 soft assignment

第一阶段建议先做第一种，更稳。

## 5. 为什么这条路线更合理

### 5.1 更符合任务真值结构

你的 benchmark 不是一般纹理回归，而是明显的分区材料问题。

### 5.2 更容易稳定训练

直接回归 `lambda(x, y), mu(x, y)` 时，网络自由度太大。

界面感知表示把自由度压缩到了：

- 一个界面函数
- 少量区域材料参数

这通常更容易识别。

### 5.3 更像论文创新

这个创新不是“把 MLP 变复杂”，而是：

- 根据逆问题本身的结构重写材料表达方式
- 把 solid mechanics inverse problem 从“平滑场拟合”改成“界面识别 + 参数识别”

这比简单堆网络更有论文味道。

## 6. 新方法的损失函数设计

推荐总损失：

`L = L_momentum + L_constitutive + L_obs + L_interface + L_param`

### 6.1 必选项

| 损失项 | 含义 | 是否必须 |
|---|---|---|
| `L_momentum` | 动量平衡残差 | 必须 |
| `L_constitutive` | 本构关系残差 | 必须 |
| `L_obs` | 稀疏位移观测误差 | 必须 |

### 6.2 推荐项

| 损失项 | 含义 | 是否推荐 |
|---|---|---|
| `L_interface` | 界面正则，如 `|grad m|` 或面积平滑 | 推荐 |
| `L_param` | 区域材料参数的物理先验/正值约束 | 推荐 |

### 6.3 正值约束

材料参数推荐统一通过 `softplus` 参数化：

- `lambda_bg > 0`
- `mu_bg > 0`
- `lambda_inc > 0`
- `mu_inc > 0`

## 7. 推荐训练策略

### 第一阶段：PINN baseline 预热

先只用当前 `PINN` 跑通任务，确认：

- 采样没问题
- 噪声设置没问题
- 指标没问题

### 第二阶段：冻结界面外形简单初始化

对于 `single_inclusion`：

- 可先让 `phi(x, y)` 从一个简单圆形先验开始
- 或者让 `mask net` 从接近常值开始，再慢慢学习

### 第三阶段：分阶段优化

推荐顺序：

1. 先训练 `state net`
2. 再训练 `interface/material`
3. 最后 joint fine-tune

### 第四阶段：界面锐化

随着训练推进，逐步增大 `alpha`，让 `sigmoid(alpha * phi)` 更接近清晰界面。

## 8. 与现有 PINN baseline 的公平比较方式

必须固定：

1. 相同几何
2. 相同观测点数量
3. 相同噪声水平
4. 相同训练步数预算
5. 相同随机种子
6. 相同测试网格
7. 相同评价指标

不能通过多给新方法训练轮数、采样点、人工调更优 stopping 来作弊。

## 9. 实验设计

### 9.1 主实验

| 编号 | 实验 | 目的 |
|---|---|---|
| M1 | `layered`: `PINN` vs 方向 A 方法 | 验证最简单分区任务 |
| M2 | `single_inclusion`: `PINN` vs 方向 A 方法 | 第一主实验 |
| M3 | `double_inclusion`: `PINN` vs 方向 A 方法 | 验证多区域情况 |

### 9.2 鲁棒性实验

| 编号 | 实验 | 设置 |
|---|---|---|
| R1 | 观测点数量 | `50/100/250/500/1000` |
| R2 | 噪声水平 | `0%/1%/3%/5%` |
| R3 | 多随机种子 | `3~5` 个 seed |

### 9.3 消融实验

| 编号 | 实验 | 目的 |
|---|---|---|
| A1 | 去掉 `interface regularization` | 看界面正则是否必要 |
| A2 | 去掉分阶段训练 | 看 staged training 是否必要 |
| A3 | 固定 `alpha` vs 逐步锐化 | 看界面锐化是否有效 |
| A4 | 直接回归材料场 vs 界面感知表示 | 证明新表示方式有价值 |

## 10. 评价指标

所有方法必须统一报告：

| 指标 | 含义 |
|---|---|
| `lambda` 相对 `L2` 误差 | 材料场恢复精度 |
| `mu` 相对 `L2` 误差 | 材料场恢复精度 |
| `ux, uy` 相对 `L2` 误差 | 位移场恢复质量 |
| `sxx, syy, sxy` 相对 `L2` 误差 | 应力场恢复质量 |
| `observation_mse` | 观测拟合误差 |
| `pde_residual_mean_abs` | 物理一致性 |
| `material_field_mean_abs_vector_error` | 材料场整体误差 |
| 训练时间 | 计算代价 |
| 参数量 | 模型规模 |

如果后面界面识别足够清晰，再补：

- 界面 IoU
- 夹杂中心误差
- 半径误差

## 11. FEM 数据怎么解决

当前没有商业 FEM 软件，不影响我们继续做。

推荐路线：

1. 第一阶段继续使用当前构造真解 benchmark
2. 第二阶段引入 Python FEM
   - 推荐 `scikit-fem`
   - 备选 `SfePy`
3. 导出为统一 `npz`
4. 保持训练/评估接口不变

这条路线不需要修改服务器系统配置。
