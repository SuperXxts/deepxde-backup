# Computers and Geotechnics 主线实验总方案

本文档用于约束第二篇 PINN 反演论文的全部后续实验。原则是：实验不是随意挑选几组能跑出来的结果，而是围绕一个清晰科学问题，形成可以支撑 `Computers and Geotechnics` 投稿的证据链。

## 1. 总体定位

目标期刊主线按 `Computers and Geotechnics` 组织。论文不写成单纯的深度学习模型改进，而写成岩土工程反演可信性问题：

> 在岩土/岩石材料参数场反演中，当加载边界存在幅值错误、形状错误、局部缺失或只知道部分信息时，标准 PINN/PFNN 是否会把边界误差错误解释成虚假的材料非均质性？如果会，能否通过低维边界参数化、边界-材料残差解耦、全局反力信息和少量边界位移锚点恢复反问题的可识别性？

这条主线必须贯穿所有实验。每一组实验都必须回答一个明确的审稿问题，不能为了堆工作量而随意增加工况。

## 2. 核心假设与需要证明的结论

论文需要证明的不是“PINN 比 FEM 正向求解快”，也不是“网络更复杂所以更好”，而是下面四个层层递进的结论：

1. 错误或缺失的边界条件会污染空间变材料场反演。
2. 只依靠位移观测和标准 PFNN，边界误差与材料误差存在不可忽略的耦合。
3. 单独增加网络容量或单独学习一个边界幅值不能稳定解决这个耦合问题。
4. 低维边界分支、解耦观测残差、总反力约束和少量边界锚点组合后，可以更稳定地分离边界误差和材料非均质性。

如果后续实验不能支持这四点，就不应进入论文写作阶段。

## 3. 审稿人问题与证据链

| 审稿人可能追问的问题 | 必须提供的证据 |
|---|---|
| 错误边界真的会污染材料反演吗？ | A 组解析机制消融；B 组 FEM 地基主算例 |
| 解析算例是不是人为构造出来的？ | B 组工程化 FEM 算例复现同一现象 |
| 位移观测点这么少，方法还能工作吗？ | D 组稀疏监测布局 |
| 位移观测含噪后是否稳定？ | C 组噪声鲁棒性 |
| 只学习一个边界幅值是否足够？ | B/E/F 组中与完整方法对比 |
| 总反力和边界锚点是否有工程意义？ | F 组锚点数量、位置、反力噪声消融 |
| 效果是不是单纯来自网络更宽或分支更多？ | A/B/H 中宽 PFNN、分支无解耦、完整方法对比 |
| 方法是否依赖某一个材料拓扑？ | G 组多类岩土材料场 |
| 为什么不用传统 FEMU 或正则化反演？ | H 组传统数值反演对比 |
| 结果是否稳定、可复现？ | 关键组多随机种子，保存配置、日志、权重、指标和图件 |

## 4. 总体实验阶段

实验只按下面顺序推进。上一阶段没有通过审查，不进入下一阶段。

| 阶段 | 名称 | 作用 | 通过标准 |
|---|---|---|---|
| A | 解析机制消融 | 验证边界误差污染机制和方法模块有效性 | 已完成 A0-A15；完整方法 A15 显著优于关键基线 |
| B | FEM 岩土主算例 | 把机制迁移到工程数值场景 | B7 完整方法在 FEM 数据上优于 PFNN、宽 PFNN和关键消融 |
| C | 噪声鲁棒性 | 模拟监测误差和 DIC/位移测量噪声 | 噪声增大时完整方法退化可控，仍优于关键基线 |
| D | 观测稀疏性 | 回答工程监测点少和“插值即可”的质疑 | 在少量监测点和局部测线条件下仍具有优势 |
| E | 边界错误类型 | 证明方法不只适用于 A=0.85 | 幅值、形状、局部未知、加载宽度错误均有合理表现 |
| F | 锚点与反力消融 | 解释锚点和总反力的作用边界 | 得到清楚的锚点数量、反力权重和噪声敏感性规律 |
| G | 材料拓扑泛化 | 证明不依赖单一材料场 | 分层、软弱夹层、透镜体、倾斜弱带等至少三类成立 |
| H | 对比方法 | 与同类 PINN 和传统数值反演比较 | 在本文目标病态场景中优于或更稳于对比方法 |

## 6. 下一阶段 B：FEM 岩土主算例

B 组是当前必须优先完成的核心实验。它回答的问题是：解析算例中发现的边界污染机制，是否也会在工程化 FEM 地基反演数据中出现。

### 6.1 工程场景

采用二维平面应变地基加载板算例。所有长度以加载板宽度 `B` 归一化，因此不是“1×1 单位方形小板”，而是工程中常见的归一化地基模型。

| 项目 | 设置 |
|---|---|
| 计算域 | 宽 `6B`，深 `3B` |
| 加载板 | 顶部中心宽度 `B` 的刚性加载板 |
| 加载方式 | 位移控制，真实竖向沉降幅值为 `A=1.0` 的归一化幅值 |
| 错误边界 | 训练模型误用 `A=0.85` 或误用边界形状 |
| 分析类型 | 小变形二维平面应变线弹性 |
| 底部边界 | 水平位移 `u=0`，竖向位移 `v=0` |
| 左右边界 | 水平位移 `u=0`，竖向方向自由 |
| 顶部非加载区 | 自由边界 |
| 加载板反力 | 一个总反力标量，由 FEM 真值积分得到 |

这里 `u` 是水平位移，`v` 是竖向位移。

### 6.2 材料场

B 组必须使用独立的 `K(x,y)` 和 `mu(x,y)`，再换算 `E(x,y)` 和 `nu(x,y)` 展示，不能继续只学习一个共同材料尺度。

主材料场应具有岩土工程含义：

| 组成 | 工程意义 |
|---|---|
| 成层背景刚度 | 沉积地层或风化程度分带 |
| 软弱夹层 | 软弱夹层、滑移带或夹泥层 |
| 局部软弱透镜体 | 局部不良地质体 |
| 平滑随机扰动 | 空间变异性，避免过度理想化 |

材料参数必须满足：

1. `K(x,y) > 0`，`mu(x,y) > 0`。
2. 换算得到的 `nu(x,y)` 保持在岩土线弹性常用范围内，例如约 `0.20-0.40`。
3. 刚度对比不能过分夸张，主算例建议软弱区刚度为背景的 `0.35-0.60`，后续再做强对比材料场泛化。

### 6.3 点数与数据划分

点数使用整数，避免给审稿人留下不必要追问。需要区分“观测点”和“物理配点”：观测点是真实可测数据；PDE 内点和边界配点不是传感器，只是 PINN 训练时的物理残差采样点。

| 点集 | B 组主设置 | 是否参与训练 | 说明 |
|---|---:|---|---|
| 位移观测点 | 120 | 是 | 模拟有限监测点或低分辨率全场观测，不使用几千个观测点 |
| PDE 内点 | 2000 | 是 | 平衡方程和本构一致性残差点，不是观测数据 |
| 边界配点 | 600 | 是 | 底部、侧边、顶部自由区和加载区边界残差 |
| 边界锚点 | 4 或 8 | 仅完整方法/消融中使用 | 加载板附近少量可靠位移点 |
| 反力积分点 | 80 | 用于计算一个总反力残差 | 数值积分点，不是 80 个传感器 |
| 验证点 | 500 | 否 | 全域均匀随机点，不与训练观测点重复 |
| 测试点 | FEM 网格节点或规则网格，至少 5000 | 否 | 只用于最终误差、云图和切片图 |

这个设置可以回应“插值不就行了”的质疑：材料参数并不是在观测点直接给出的，观测点只有位移；物理配点没有材料真值；测试点只用于评价。因此不能把这些点简单理解为“几千个材料观测点”。

### 6.4 FEM 真值数据要求

B 组训练前必须先完成 FEM 数据生成与自检：

1. 保存 FEM 网格、节点位移、单元/节点应力、`K/mu/E/nu` 真值场。
2. 保存加载板总反力真值和反力积分曲线。
3. 做至少一次网格收敛检查，说明选用网格足以作为反演真值。
4. 画出真值材料场、位移场、应力场、加载板反力分布，确认没有边界或符号错误。
5. 所有 FEM 数据生成脚本必须固定随机种子并保存配置文件。

### 6.5 B 组工况矩阵

B 组不允许临时增删。先跑 B0-B7 的 3000 步 smoke，全部通过后再跑 150000 步正式实验。

| 组别 | 方法与边界设置 | 目的 |
|---|---|---|
| B0 | DeepXDE PFNN + 正确加载边界 | 理想边界下的 FEM 工程基线 |
| B1 | DeepXDE PFNN + 固定错误边界 `A=0.85` | 证明错误边界在 FEM 场景中也会污染材料反演 |
| B2 | DeepXDE PFNN + 可学习边界幅值 `A` | 检查单独学习幅值是否足够 |
| B3 | DeepXDE PFNN + 可学习 `A` + 总反力 | 检查总反力是否补充整体刚度尺度 |
| B4 | 分支网络 + 可学习 `A` + 本构反力 | 排除“只要分支网络加反力就够”的可能 |
| B5 | 边界分支 + 普通观测残差 + 本构反力 | 检查边界分支不解耦时是否仍会混淆 |
| B6 | 边界分支 + 解耦观测残差 + 本构反力 | 验证解耦训练器的核心贡献 |
| B7 | 完整方法：边界分支 + 解耦观测 + 锚点 + 本构反力 | FEM 主算例最终方法 |

通过标准不是要求 B7 在所有指标上绝对最优，而是要求结论逻辑成立：

1. B1 明显劣于 B0，证明边界错误污染材料反演。
2. B2/B3 有改善但不能完全替代完整方法。
3. B5 与 B6 的差异能说明解耦训练的必要性。
4. B7 在 `K`、`mu`、`E`、`nu`、边界幅值、总反力误差和材料场图上综合最稳。

## 7. B 组通过后才进入的补充实验

### 7.1 C 组：噪声鲁棒性

只选择关键方法，不重复全部 B0-B7。

| 方法 | 噪声水平 |
|---|---|
| PFNN + 固定错误边界 | 0%, 1%, 3%, 5% |
| PFNN + 可学习 A + 反力 | 0%, 1%, 3%, 5% |
| 完整方法 | 0%, 1%, 3%, 5% |

噪声加在位移观测上，按位移幅值归一化。正式论文建议每个噪声水平至少 3 个随机种子，最终可根据计算资源扩展到 5 个。

### 7.2 D 组：观测稀疏性与工程监测布局

重点不是单纯全域随机稀疏，而是模拟岩土工程更常见的监测布置。

| 布局 | 点数 | 工程含义 |
|---|---:|---|
| 全域稀疏随机点 | 25, 50, 100, 150 | 低分辨率全场位移 |
| 地表沉降线 + 少量内部点 | 25, 50, 100 | 地表沉降监测与少量内部测点 |
| 1-3 条竖向测线 | 25, 50, 100 | 测斜孔、钻孔内位移或剖面监测 |
| 加载板附近局部窗口 | 25, 50, 100 | 局部 DIC 或近场监测 |

每个布局至少比较：PFNN 错误边界、PFNN 可学习 A + 反力、完整方法。

### 7.3 E 组：边界错误类型

| 错误类型 | 设置 |
|---|---|
| 幅值偏小 | `A=0.75`, `A=0.85` |
| 幅值偏大 | `A=1.15` |
| 形状错误 | 加载板位移包含倾斜项或局部弯曲项 |
| 部分未知加载 | 只知道板中心位移，不知道板边缘分布 |
| 加载宽度错误 | 模型假定 `B`，真实为 `0.8B` 或 `1.2B` |

关键比较是：只学习 `A`、学习低维边界模式、完整方法。

### 7.4 F 组：锚点和反力消融

| 变量 | 设置 |
|---|---|
| 锚点数量 | 0, 2, 4, 8 |
| 锚点位置 | 加载板下均匀布置、板边缘优先布置 |
| 反力信息 | 无反力、无噪声总反力、1%-5% 噪声总反力 |
| 反力权重 | 1, 5, 10 |

必须输出材料误差、边界幅值误差、总反力误差随锚点数量和反力权重变化的曲线。

### 7.5 G 组：材料拓扑泛化

| 材料拓扑 | 工程含义 |
|---|---|
| 成层地基 | 沉积土层 |
| 软弱夹层 | 软弱带、夹泥层、潜在滑移面 |
| 局部软弱透镜体 | 局部不良地质体 |
| 倾斜弱带 | 断层、结构面或倾斜软弱带 |
| 平滑随机场 | 空间变异性 |

每类材料场至少跑：PFNN 错误边界、PFNN 可学习 A + 反力、完整方法。

### 7.6 H 组：对比方法

| 方法 | 作用 |
|---|---|
| DeepXDE PFNN | 官方 PINN baseline |
| 宽 PFNN | 排除网络容量影响 |
| 分支网络 + 可学习 A | 排除单纯结构分支贡献 |
| 边界分支无解耦 | 证明解耦机制必要 |
| 完整方法 | 本文方法 |
| FEMU 低维分区反演 | 传统数值反演基线 |
| FEMU/KLE 或 Tikhonov 场反演 | 传统高维正则化反演基线 |

传统方法如果在边界准确、材料分区已知、低维参数条件下更好，需要如实报告。本文强调的优势场景是：边界错误或缺失、材料场高维、拓扑未知、位移观测稀疏含噪。

## 9. 运行纪律

1. 不在本地电脑运行 PINN 长实验。
2. 长实验必须先做 smoke，再做正式长跑。
3. 正式实验启动后必须给出预计完成时间。
4. 判断实验是否 live，必须同时检查活进程、日志时间戳和 step 是否增长。
5. 不把旧日志、失败快照或历史 screen 当作当前 live 状态。
6. 不覆盖同名正在运行实验；需要重跑时，先保留失败快照，再显式停止旧任务。
7. 失败时先区分代码错误、环境错误、启动链路错误和外部中断。
8. 所有关键实验必须保存足够产物用于复核。
