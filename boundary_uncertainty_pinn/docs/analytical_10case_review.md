## 3. 当前可以支持的结论

1. 错误边界幅值会严重污染材料反演。固定错误 `A=0.85` 时，材料误差从 7% 左右上升到 50% 以上。

2. 只加入反力但不修正错误边界，不能恢复材料场。`wrong_fixed_A_reaction` 的反力误差被压到 0.57%，但材料误差进一步达到 63.16%。这说明模型可以用错误材料场去凑合力，但边界错误仍然污染材料反演。

3. 把边界幅值显式设为可学习参数是有效的。`learnable_A` 能从错误初值 0.85 学到 0.9977，并把材料误差从 50.52% 降到 7.05%。

4. 全局反力信息对刚度尺度识别非常关键。`learnable_A_reaction` 和 `learnable_A_anchor_reaction` 的材料误差分别降到 3.67% 和 3.37%。

5. 单独加入少量边界锚点并不稳定。`learnable_A_anchor` 虽然把 A 学到 1.0004，但材料误差为 12.85%。这说明边界锚点不是万能信息，少量局部位移点不能替代全局力学尺度约束。

## 4. 代码与数值设置审查

### 4.1 暂未发现能直接推翻当前 10 组结论的实现错误

当前代码中的基本小变形线弹性方程、平面应变本构关系、顶部位移边界、底部固定边界、左右完整边界、材料尺度场和误差指标计算在逻辑上是一致的。

当前 PFNN 输出：

```text
u, v, sigma_xx, sigma_yy, sigma_xy, m
```

其中：

```text
K = K0 exp(m)
mu = mu0 exp(m)
```

因此当前不是独立反演 `K(x,y)` 和 `mu(x,y)`，而是反演一个共同刚度尺度场。`K`、`mu`、`E` 的误差接近相同是参数化导致的正常现象，不是程序错误。

### 4.2 反力积分实现是合理的，但论文表述必须谨慎

当前反力约束是：

```text
R_y = integral_top sigma_yy(x,1) dx
```

代码用 200 个顶部积分点和梯形权重近似这个积分。这里的 200 个点不是 200 个反力传感器，而是数值积分点。真实工程解释应是：加载系统或反力架给出一个总反力观测，模型训练时用边界应力场积分得到预测总反力。

实现上，`PointSetOperatorBC` 把同一个积分残差复制到 200 个积分点上求均方误差。由于 DeepXDE 最终对这些点取均值，这等价于约束一个总反力残差，不会因为 200 个点把损失放大 200 倍。后续可以把这一段封装得更清楚，但当前结果不因此失效。

### 4.3 当前最大的科学局限：制造解体力项

解析算例使用制造解。体力项 `f_x, f_y` 是由真实应力场反推出来的：

```text
f_x = partial sigma_xx_true / partial x + partial sigma_xy_true / partial y
f_y = partial sigma_xy_true / partial x + partial sigma_yy_true / partial y
```

这对代码验证是合理的，但对材料反演论文有风险：这个体力项本身含有真实材料场和真实位移场的信息。虽然所有工况使用同一个体力项，因此 10 组之间的相对对比仍然有意义，但不能把这个解析算例作为论文主证据。

论文中应把解析算例定位为：

```text
机制验证、可识别性诊断、代码正确性验证。
```

不能把它定位为：

```text
已经充分证明岩土工程实际问题。
```

### 4.4 当前材料模型还不够完整

当前固定泊松比 `nu=0.30`，只反演共同刚度尺度场。这适合第一阶段揭示边界幅值与材料尺度的耦合，但还不能代表更一般的岩土材料反演。

后续至少应补：

```text
K 和 mu 双场反演；
或 E 和 nu 双场反演；
或在 FEM 岩土算例中明确说明 nu 固定是工程先验。
```

### 4.5 当前训练策略还偏基础

当前正式结果只用 Adam 训练 150000 步，没有 L-BFGS、没有自适应损失权重、没有多随机种子统计。作为机制验证可以接受，但如果目标是 CMAME 或 Computers and Geotechnics，后续需要补训练稳定性和可复现性证据。

本轮按用户要求暂不启动多随机种子。

## 5. 站在不同审稿专家角度的判断

### 5.1 数值模拟专家会关心什么

他们会认可当前 10 组对照矩阵的逻辑，因为同一个解析真值下只改变边界信息和反力信息，能清楚揭示可识别性变化。

但他们也会追问：

```text
为什么不用传统 FEM 更新、伴随反演或贝叶斯反演？
制造解体力项是否向反演泄露了材料信息？
单位方形解析算例是否过于理想？
只用单随机种子是否稳定？
只用 PFNN 是否足够？
```

### 5.2 岩土工程专家会关心什么

他们会觉得“边界/加载信息不准导致参数反演偏差”是合理问题，但单位方形解析算例不够工程化。

后续必须补一个或多个 FEM 岩土算例，例如：

```text
平面应变地基 + 顶部刚性加载板；
软弱夹层或软弱透镜体；
边界位移幅值存在 10%-20% 标定误差；
观测来自地表沉降线、内部测线或 DIC-like 降采样位移场；
总反力来自加载系统。
```

### 5.3 计算机/PINN 专家会关心什么

他们会认可用 PFNN 做 DeepXDE baseline 的公平性，但会认为“PFNN + 一个可学习标量 A”方法创新不够强。

如果投 CMAME，最好进一步加入：

```text
边界不确定性的可识别性分析；
反力观测对材料尺度的敏感性分析；
与标准 PINN/PFNN、硬边界 PINN、传统 FEMU/伴随反演的公平对比；
更一般的边界参数化，而不只是一个幅值 A；
双材料场 K/mu 或 E/nu 的扩展。
```

## 6. 这条故事线有没有顶刊价值

不能简单说“错误边界会污染材料反演”就是顶刊创新。这个现象在反问题领域是常识：模型误差、边界误差和观测误差都会导致参数估计偏差。PINN 领域也已有大量工作讨论边界条件约束、未知边界、材料识别和反问题。

这条线真正可能有价值的地方是更具体的科学问题：

```text
在空间变材料场反演中，标准 PINN/PFNN 是否会把边界幅值误差系统性吸收到材料刚度场？
这种污染在什么观测条件下发生？
仅靠位移观测为什么不能稳定拆分边界尺度和材料尺度？
一个全局反力观测为什么能显著恢复材料刚度尺度的可识别性？
这种机制在工程化 FEM 岩土问题中是否仍然成立？
```

也就是说，论文不能写成“我们改了 PINN 模型，所以更准”。应该写成：

```text
我们研究边界信息不完备条件下材料反演的可识别性失败机制，并提出一个显式边界不确定性 + 全局反力约束的物理信息反演框架。
```

## 7. 当前顶刊风险判断

### 7.1 只凭当前 10 组解析算例，不能投顶刊

原因：

```text
解析算例过于理想；
制造解体力项有信息泄露嫌疑；
没有 FEM 岩土主算例；
没有传统反演对比；
没有噪声、稀疏性、边界误差幅值扫描；
没有多随机种子；
材料参数化仍是固定 nu 的单尺度场。
```

### 7.2 如果补齐后续工作，Computers and Geotechnics 更现实

如果加入工程化 FEM 地基/岩体算例，并把观测方式设计成岩土领域熟悉的沉降线、内部测线、加载板反力，那么这条故事线更适合 Computers and Geotechnics。

### 7.3 CMAME 需要更强方法贡献

CMAME 不太会接受“一个工程应用 + PFNN baseline + 可学习 A”的普通故事。要冲 CMAME，需要把方法上升到更一般的边界-材料联合可识别性框架，并加入传统 FEMU/伴随法基线、敏感性分析、双材料场扩展和更强的训练策略。

## 8. 下一步建议

暂不跑多随机种子。下一步应先做：

1. 设计 FEM 岩土主算例：平面应变地基、加载板、软弱夹层/透镜体、总反力观测。
2. 把当前解析算例固定为机制验证章节，不再过度扩展。
3. 加入传统反演基线的最小可复现版本，用同样的观测点和同样的边界错误设置。
4. 增加边界幅值误差扫描，例如 `A_fixed=0.70, 0.80, 0.85, 0.90, 0.95`。
5. 增加观测稀疏性和噪声实验，但应在 FEM 工程算例上做，而不是只在单位方形制造解上做。
