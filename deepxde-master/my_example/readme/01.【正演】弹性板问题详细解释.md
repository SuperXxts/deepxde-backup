## 1. 概述

### 1.1 问题简介

本代码使用PINN（Physics-Informed Neural Network）方法求解一个**2D线性弹性板问题**，计算在给定外力作用下弹性板的位移场和应力场。

### 1.2 问题特点

- **求解域**：单位正方形板 [0,1] × [0,1]
- **未知量**：位移场 `[ux, uy]` 和应力场 `[Sxx, Syy, Sxy]`
- **方法**：PINN（无监督学习，无需标签数据）
- **验证**：有精确解（解析解），用于验证PINN精度

### 1.3 核心物理方程

1. **几何方程**（应变-位移关系）
2. **本构方程**（应力-应变关系，胡克定律）
3. **平衡方程**（动量守恒）

## 2. 术语说明

### 2.1 线性弹性（Linear Elasticity）

**为什么叫"线性弹性板"？**

"线性"指的是**应力与应变之间的线性关系**（胡克定律）：

```python
# 线性本构关系（胡克定律）
Sxx = E_xx*(2*mu + lambda) + E_yy*lambda
Syy = E_yy*(2*mu + lambda) + E_xx*lambda
Sxy = 2*mu*E_xy
```

**关键特征**：
1. **应力与应变成正比**：应力 = 常数 × 应变（一次函数，没有平方项、立方项等）
2. **材料参数是常数**：`lambda` 和 `mu` 是常数，不随应变变化
3. **可逆性**：卸载后完全恢复原状（弹性）

**对比**：
- **非线性弹性**：应力与应变不是线性关系（可能包含 `E_xx²`、`E_xx³` 等项）
- **塑性**：应力超过屈服极限后，产生永久变形

### 2.2 PDE（Partial Differential Equation，偏微分方程）

**PDE** 是 **Partial Differential Equation（偏微分方程）** 的缩写。

**简单理解**：
- **常微分方程（ODE）**：只涉及一个变量的导数，如 `dy/dx = x`
- **偏微分方程（PDE）**：涉及多个变量的偏导数，如 `∂u/∂x + ∂u/∂y = 0`

**在弹性力学中**：
- 平衡方程：`∂Sxx/∂x + ∂Sxy/∂y - fx = 0` ← 这是一个PDE

**在PINN中**：
- **PDE残差**：PDE方程应该等于0，但实际计算不为0的差值
- **PDE损失**：所有PDE残差的均方误差，用于约束神经网络满足物理定律

### 2.3 残差 vs 损失函数

**残差（Residual）**：PDE方程应该等于0，但实际不为0的差值
- 例如：`momentum_x = ∂Sxx/∂x + ∂Sxy/∂y - fx`（这是一个残差）

**损失函数（Loss）**：残差的均方误差（MSE）
- 例如：`loss = ||momentum_x||² = mean(momentum_x²)`

**使用规范**：
- 描述**计算过程**时，用"残差"（PDE函数计算残差）
- 描述**损失函数**时，用"均方误差"（损失函数是残差的均方误差）

## 3. 问题描述

### 3.1 物理问题

**求解域**：单位正方形板 [0,1] × [0,1]

**未知量**：
- 位移场：`u = (ux, uy)` [x方向和y方向的位移]
- 应力场：`σ = (Sxx, Syy, Sxy)` [正应力和剪应力]

### 3.2 控制方程

#### 3.2.1 几何方程（应变-位移关系）

```python
E_xx = ∂ux/∂x          # x方向正应变
E_yy = ∂uy/∂y          # y方向正应变
E_xy = 0.5*(∂ux/∂y + ∂uy/∂x)  # 剪应变
```

#### 3.2.2 本构方程（应力-应变关系，胡克定律）

```python
Sxx = E_xx*(2*mu + lambda) + E_yy*lambda
Syy = E_yy*(2*mu + lambda) + E_xx*lambda
Sxy = 2*mu*E_xy
```

其中：
- `lambda (λ)`：拉梅常数
- `mu (μ)`：剪切模量

#### 3.2.3 平衡方程（动量守恒）

```python
∂Sxx/∂x + ∂Sxy/∂y = fx  # x方向力平衡
∂Sxy/∂x + ∂Syy/∂y = fy  # y方向力平衡
```

其中：`fx, fy` 是体积力（body force）

### 3.3 控制方程的通用性

**这三个方程是线性弹性力学的通用方程**，适用于：
- ✅ 所有线性弹性问题
- ✅ 小变形（位移 << 物体尺寸）
- ✅ 静力学问题（无惯性力）

**不适用于**：
- ❌ 大变形（需要几何非线性）
- ❌ 塑性变形（需要本构非线性）
- ❌ 动力学问题（需要添加惯性项）

## 4. 材料参数和边界条件

### 4.1 材料参数

#### 4.1.1 参数含义

- **lmbd (λ, 拉梅常数)**：描述材料的体积压缩特性
- **mu (μ, 剪切模量)**：描述材料的抗剪切变形能力
- **Q = 4.0**：问题参数（载荷强度系数），用于构造精确解和边界条件

#### 4.1.2 参数设置要求

1. **lmbd 和 mu 必须 > 0**（物理上要求材料有正的弹性模量）
2. **lmbd 和 mu 的比值影响泊松比**：
   - 泊松比 ν = λ / (2(λ + μ))
   - 对于大多数材料，泊松比在 0 到 0.5 之间
3. **Q 可以任意设置**，但会影响边界载荷的大小和数值计算的稳定性

#### 4.1.3 实际工程中的参数

在实际工程中，这些参数来自材料实验：
- **混凝土**：λ ≈ 10 GPa, μ ≈ 10 GPa
- **钢材**：λ ≈ 100 GPa, μ ≈ 80 GPa
- **橡胶**：λ ≈ 0.001 GPa, μ ≈ 0.0001 GPa

**代码中使用归一化值（1.0, 0.5）是为了数值计算的方便**，实际应用时需要根据真实材料参数进行量纲转换。

### 4.2 边界条件

#### 4.2.1 位移边界条件（Dirichlet BC）

- **上边界（y=1）**：ux = 0（x方向不能移动）
- **下边界（y=0）**：ux = 0, uy = 0（x和y方向都不能移动）
- **左边界（x=0）**：uy = 0（y方向不能移动）
- **右边界（x=1）**：uy = 0（y方向不能移动）

**物理意义**：
- 下边界完全固定（像板子被钉在地上）
- 左、右边界只能沿x方向移动（像板子被卡在垂直槽中）
- 上边界只能沿y方向移动（像板子被卡在水平槽中）

#### 4.2.2 应力边界条件（Neumann BC）

- **左边界（x=0）**：Sxx = 0（无x方向表面力）
- **右边界（x=1）**：Sxx = 0（无x方向表面力）
- **上边界（y=1）**：Syy = (2*mu + lambda) * Q * sin(πx)（**施加y方向的力**）

**物理意义**：
- 上边界受到**垂直方向的拉力或压力**（沿x方向呈正弦分布）
- 这是导致板子变形的主要原因

**重要说明**：
- 在这个代码中，上边界的载荷 `Syy = (2*mu + lambda) * Q * sin(πx)` **是从精确解计算出来的**，不是随意给定的！
- 构造过程：先假设位移场 → 计算应变 → 计算应力 → 在边界上，应力值就是边界条件
- 在实际工程中，载荷是**给定的**（例如：上边界施加 100 N 的力），然后使用 PINN 求解
- 这个例子是为了验证 PINN 方法，所以先构造精确解，再反推出边界载荷

### 4.3 模型限制

**这个模型是线性弹性模型，只能模拟**：
- ✅ 小变形（位移 << 板子尺寸）
- ✅ 弹性变形（卸载后恢复原状）
- ✅ 线性应力-应变关系

**不能模拟**：
- ❌ 大变形（几何非线性）
- ❌ 塑性变形（永久变形）
- ❌ 断裂（材料失效）
- ❌ 损伤（材料性能退化）

### 4.4 应力的方向定义

#### 4.4.1 正应力（Normal Stress）

- **Sxx**：作用在**垂直于x轴的平面**上，**沿x方向**的应力
- **Syy**：作用在**垂直于y轴的平面**上，**沿y方向**的应力

#### 4.4.2 剪应力（Shear Stress）

- **Sxy**：作用在**垂直于x轴的平面**上，**沿y方向**的应力

#### 4.4.3 应力张量

在2D情况下，应力张量是：

```
σ = [ Sxx  Sxy ]   ← 第一行：作用在垂直于x轴的平面上的应力
    [ Sxy  Syy ]   ← 第二行：作用在垂直于y轴的平面上的应力
```

## 5. 精确解构造

### 5.1 为什么需要精确解？

在这个代码中，精确解用于：
- ✅ **验证PINN的精度**（比较预测值与真值）
- ✅ **评估模型性能**（计算L2相对误差）
- ✅ **调试代码**（确保实现正确）

**在实际工程问题中，通常没有精确解**，只能：
- 依赖PINN求解
- 或使用有限元法（FEM）作为参考解

### 5.2 精确解的构造过程

精确解是根据控制方程**反推**出来的。具体过程：

1. **先假设位移场的形式**（必须满足边界条件）
2. **通过几何方程计算应变**
3. **通过本构方程计算应力**
4. **检查是否满足平衡方程**
5. **如果不满足，调整位移场或添加体积力**，使得平衡方程成立

### 5.3 精确解的数学推导

#### 5.3.1 假设位移场

```python
ux = cos(2πx) * sin(πy)
uy = sin(πx) * Q * y^4 / 4
```

**为什么选择这个位移场？**

1. **满足边界条件**：
   - 上下边界 ux=0：在 y=0 和 y=1 时，`sin(πy) = 0` → `ux = 0` ✓
   - 左右边界 uy=0：在 x=0 和 x=1 时，`sin(πx) = 0` → `uy = 0` ✓
   - 下边界 uy=0：在 y=0 时，`y^4 = 0` → `uy = 0` ✓

2. **这是人为构造的解析表达式**：
   - 目的是构造一个已知精确解的问题，用于验证PINN方法
   - 选择三角函数和多项式是为了满足边界条件、便于计算导数、得到光滑的解析解

#### 5.3.2 计算应变（几何方程）

```python
E_xx = ∂ux/∂x = -2π * sin(2πx) * sin(πy)
E_yy = ∂uy/∂y = sin(πx) * Q * y^3
E_xy = 0.5*(∂ux/∂y + ∂uy/∂x) = ...
```

#### 5.3.3 计算应力（本构方程）

```python
Sxx = E_xx*(2*mu + lambda) + E_yy*lambda
Syy = E_yy*(2*mu + lambda) + E_xx*lambda
Sxy = 2*mu*E_xy
```

#### 5.3.4 反推体积力（使平衡方程成立）

```python
# 平衡方程：∂Sxx/∂x + ∂Sxy/∂y - fx = 0
# 移项得到：fx = ∂Sxx/∂x + ∂Sxy/∂y
fx = ∂Sxx/∂x + ∂Sxy/∂y  # 从平衡方程反推
fy = ∂Sxy/∂x + ∂Syy/∂y
```

**注意**：
1. 体积力 `fx` 和 `fy` 是根据精确解**反推**出来的，不是物理上给定的！
2. 代码中 `fx(x)` 和 `fy(x)` 的表达式可能包含负号，这是因为从精确解计算出的实际体积力值可能为负（取决于应力的空间导数），但公式本身是正确的。

### 5.4 体积力函数

#### 5.4.1 体积力 vs 表面力

**体积力（Body Force）**：
- 作用在物体**内部每一点**的力
- 例如：重力、电磁力、惯性力
- 单位：N/m³（力/体积）

**表面力（Surface Force）**：
- 作用在物体**表面**的力
- 例如：压力、拉力、摩擦力
- 单位：N/m²（力/面积）

#### 5.4.2 函数参数名的含义

```python
def fx(x):
    """
    x: 空间坐标点，形状为 (N, 2)，包含 [x坐标, y坐标]
    注意：参数名是 x，但实际上是包含 x 和 y 两个坐标的数组！
    """
    # x[:, 0:1] 是 x 坐标
    # x[:, 1:2] 是 y 坐标
    return ...  # 返回 x 方向的体积力
```

**为什么参数名是 x？**
- 这是编程习惯，`x` 通常表示输入变量（可以是标量、向量或数组）
- 在这个函数中，`x` 是一个形状为 `(N, 2)` 的数组，包含所有点的坐标 `[x, y]`
- 通过 `x[:, 0:1]` 访问 x 坐标，`x[:, 1:2]` 访问 y 坐标

#### 5.4.3 体积力函数的具体表达式

**x 方向的体积力 fx(x, y)**：

```python
fx(x, y) = -λ * [4π² * cos(2πx) * sin(πy) - Q * y³ * π * cos(πx)]
          - μ * [π² * cos(2πx) * sin(πy) - Q * y³ * π * cos(πx)]
          - 8μ * π² * cos(2πx) * sin(πy)
```

**y 方向的体积力 fy(x, y)**：

```python
fy(x, y) = λ * [3Q * y² * sin(πx) - 2π² * cos(πy) * sin(2πx)]
          - μ * [2π² * cos(πy) * sin(2πx) + (Q * y⁴ * π² * sin(πx)) / 4]
          + 6Q * μ * y² * sin(πx)
```

**注意**：
- **两个方向都有体积力**：fx 是 x 方向的体积力，fy 是 y 方向的体积力
- **体积力是 x 和 y 的函数**：fx(x, y) 和 fy(x, y) 都依赖于两个坐标
- **这是从精确解反推出来的**：目的是使精确解满足平衡方程

#### 5.4.4 实际工程中的体积力

在实际工程中，体积力通常是**给定的**：

```python
# 重力（向下为负）
fx = 0
fy = -ρ * g  # ρ是密度，g是重力加速度

# 离心力
fx = ρ * ω² * x  # ω是角速度
fy = ρ * ω² * y

# 电磁力
fx = q * Ex  # q是电荷，Ex是x方向电场
fy = q * Ey
```

## 6. PINN方法

### 6.1 PINN概述

**PINN（Physics-Informed Neural Network）**：
- **无监督学习**：无需标签数据，仅通过物理定律约束模型训练
- **物理约束**：通过PDE残差和边界条件约束模型训练
- **构建解析解**：仅用于验证模型精度和评估误差，不参与训练过程

### 6.2 模型结构

#### 6.2.1 网络架构

```python
layers = [2, [40] * 5, [40] * 5, [40] * 5, [40] * 5, 5]
```

**详细结构**：

```
输入层：
  (N, 2)  ← [x, y] 坐标

隐藏层1（全连接 + tanh）：
  (N, 2) → (N, 40)
  参数：2 × 40 + 40 = 120

隐藏层2（全连接 + tanh）：
  (N, 40) → (N, 40)
  参数：40 × 40 + 40 = 1,640

隐藏层3（全连接 + tanh）：
  (N, 40) → (N, 40)
  参数：40 × 40 + 40 = 1,640

隐藏层4（全连接 + tanh）：
  (N, 40) → (N, 40)
  参数：40 × 40 + 40 = 1,640

输出层（全连接，无激活函数）：
  (N, 40) → (N, 5)
  参数：40 × 5 + 5 = 205

最终输出：
  (N, 5) ← [ux, uy, Sxx, Syy, Sxy]
```

**总参数数量**：约 5,245 个参数

#### 6.2.2 激活函数

**tanh（双曲正切）**：
- 输出范围：[-1, 1]
- 优点：平滑、可导、有界
- 缺点：可能梯度消失（深层网络）

**为什么选择tanh？**
- 在PINN中，tanh表现良好
- 可以学习平滑的物理场
- 避免ReLU的"死神经元"问题

#### 6.2.3 权重初始化

**Glorot uniform（Xavier初始化）**：
- 从均匀分布 U(-a, a) 采样，其中 a = sqrt(6 / (fan_in + fan_out))
- 优点：保持前向和反向传播的方差稳定
- 适用于tanh激活函数

#### 6.2.4 硬边界条件的输出变换

如果使用硬边界条件，网络输出会经过变换：

```python
# 原始输出：[ux_raw, uy_raw, Sxx_raw, Syy_raw, Sxy_raw]
# 变换后输出：[Ux, Uy, Sxx, Syy, Sxy]

Ux = ux_raw * y * (1-y)  # 自动满足上、下边界 ux=0
Uy = uy_raw * x * (1-x) * y  # 自动满足左、右、下边界 uy=0
Sxx = Sxx_raw * x * (1-x)  # 自动满足左、右边界 Sxx=0
Syy = Syy_raw * (1-y) + (lambda + 2*mu) * Q * sin(πx)  # 自动满足上边界 Syy条件
Sxy = Sxy_raw  # 无边界约束
```

**优点**：边界条件自动满足，减少优化难度

### 6.3 损失函数

#### 6.3.1 损失函数的组成

损失函数 = **PDE损失** + **边界条件损失**

**注意**：边界条件损失取决于边界条件类型：
- **硬边界条件（Hard BC）**：边界条件损失 = 0（边界条件自动满足）
- **软边界条件（Soft BC）**：边界条件损失 = 8项边界条件误差的均方误差

#### 6.3.2 PDE损失（5项）

在域内训练点上，计算PDE残差：

```python
# 1. x方向平衡方程残差
momentum_x = ∂Sxx/∂x + ∂Sxy/∂y - fx
# 应该 = 0，所以损失 = ||momentum_x||² = mean(momentum_x²)

# 2. y方向平衡方程残差
momentum_y = ∂Sxy/∂x + ∂Syy/∂y - fy
# 应该 = 0，所以损失 = ||momentum_y||² = mean(momentum_y²)

# 3. x方向应力一致性残差
stress_x = S_xx（从应变计算） - Sxx（网络输出）
# 应该 = 0，所以损失 = ||stress_x||² = mean(stress_x²)

# 4. y方向应力一致性残差
stress_y = S_yy（从应变计算） - Syy（网络输出）
# 应该 = 0，所以损失 = ||stress_y||² = mean(stress_y²)

# 5. 剪应力一致性残差
stress_xy = S_xy（从应变计算） - Sxy（网络输出）
# 应该 = 0，所以损失 = ||stress_xy||² = mean(stress_xy²)
```

**PDE损失 = 所有域内训练点上这5项残差的均方误差之和**

**数学表达式**：
```python
PDE损失 = ||momentum_x||² + ||momentum_y||² + ||stress_x||² + ||stress_y||² + ||stress_xy||²

其中，||·||² 表示L2范数的平方（均方误差）：
||momentum_x||² = (1/N) * Σ(momentum_x²) = mean(momentum_x²)
```

**DeepXDE的实现**：
- PDE函数返回**残差**：`[momentum_x, momentum_y, stress_x, stress_y, stress_xy]`
- 使用MSE（均方误差）损失函数计算损失：`loss = mean((0 - error)²) = mean(error²)`
- 对于每个残差项，计算所有训练点上的均方误差

#### 6.3.3 边界条件损失（仅适用于软边界条件）

**注意**：如果使用硬边界条件，边界条件损失 = 0（边界条件自动满足，无需计算损失）

**如果使用软边界条件**，在边界训练点上计算边界条件误差：

```python
# 位移边界条件（5项）
ux_top_error = ux（网络输出） - 0  # 上边界 ux=0
ux_bottom_error = ux（网络输出） - 0  # 下边界 ux=0
uy_left_error = uy（网络输出） - 0  # 左边界 uy=0
uy_bottom_error = uy（网络输出） - 0  # 下边界 uy=0
uy_right_error = uy（网络输出） - 0  # 右边界 uy=0

# 应力边界条件（3项）
sxx_left_error = Sxx（网络输出） - 0  # 左边界 Sxx=0
sxx_right_error = Sxx（网络输出） - 0  # 右边界 Sxx=0
syy_top_error = Syy（网络输出） - (2*mu + lambda) * Q * sin(πx)  # 上边界 Syy条件
```

**边界条件损失 = 所有边界训练点上这8项误差的均方误差之和**

#### 6.3.4 总损失函数

**情况1：硬边界条件（Hard BC）**

```python
总损失 = PDE损失 + 边界条件损失

PDE损失 = ||momentum_x||² + ||momentum_y||² + ||stress_x||² + ||stress_y||² + ||stress_xy||²
        = mean(momentum_x²) + mean(momentum_y²) + mean(stress_x²) + mean(stress_y²) + mean(stress_xy²)

边界条件损失 = 0  # 边界条件通过输出变换自动满足，无需计算损失
```

**特点**：
- 边界条件通过 `hard_BC` 函数自动满足
- 不需要在损失函数中计算边界条件误差
- 优化难度更低，训练更高效

**情况2：软边界条件（Soft BC）**

```python
总损失 = PDE损失 + 边界条件损失

PDE损失 = ||momentum_x||² + ||momentum_y||² + ||stress_x||² + ||stress_y||² + ||stress_xy||²
        = mean(momentum_x²) + mean(momentum_y²) + mean(stress_x²) + mean(stress_y²) + mean(stress_xy²)

边界条件损失 = ||ux_top_error||² + ||ux_bottom_error||² + ... + ||syy_top_error||²
              = mean(ux_top_error²) + mean(ux_bottom_error²) + ... + mean(syy_top_error²)
```

**特点**：
- 边界条件通过 `DirichletBC` 显式施加
- 需要在损失函数中计算边界条件误差
- 更灵活，但优化难度更高

#### 6.3.5 损失函数的物理意义

**PDE损失**：
- 衡量神经网络是否满足物理定律（平衡方程、本构关系）
- 越小越好（理想情况下 = 0）

**边界条件损失**：
- 衡量神经网络是否满足边界约束
- 越小越好（理想情况下 = 0）

**总损失**：
- 综合衡量模型的物理一致性
- 训练目标是让总损失 → 0

### 6.4 PINN训练需要的信息

#### 6.4.1 核心问题

**问题**：模型输入是 `[x, y]`，输出是 `[ux, uy, σxx, σyy, σxy]`，损失函数由平衡方程和应力一致性约束。**仅仅有这些信息，能唯一确定解吗？**

**答案**：**不能！** 还需要其他关键信息。

#### 6.4.2 完整信息清单

除了输入坐标 `[x, y]` 和损失函数，PINN还需要以下信息：

1. **边界条件（Boundary Conditions）** ⭐ **最关键！**
   - 边界条件提供了边界上的约束值，这是确定唯一解的关键
   - PDE方程（平衡方程、本构关系）只能确定解的**形式**，不能确定**具体值**
   - 边界条件提供了**边界上的具体约束值**，从而唯一确定解
   - 类比：微分方程的通解 + 边界条件 = 特解

2. **材料参数（Material Parameters）**
   - `lmbd = 1.0`（拉梅常数）
   - `mu = 0.5`（剪切模量）
   - 在本构关系中：`Sxx = E_xx*(2*mu + lambda) + E_yy*lambda`

3. **体积力函数（Body Force Functions）**
   - `fx(x)`, `fy(x)`
   - 在平衡方程中：`∂Sxx/∂x + ∂Sxy/∂y - fx = 0`

4. **几何域（Geometry Domain）**
   - `[0,1] × [0,1]`（单位正方形）
   - 定义边界的位置和采样点的范围

#### 6.4.3 信息流程图

```
训练信息输入：
│
├─ 1. 输入坐标：[x, y]（域内点 + 边界点）
│
├─ 2. 边界条件：
│   ├─ 位移边界：ux=0, uy=0（在特定边界上）
│   └─ 应力边界：Sxx=0, Syy=载荷（在特定边界上）
│
├─ 3. 材料参数：lmbd, mu
│
├─ 4. 体积力函数：fx(x), fy(x)
│
└─ 5. 几何域：[0,1] × [0,1]

↓

神经网络处理：
│
└─ 输出：[ux, uy, Sxx, Syy, Sxy]

↓

损失函数计算（取决于边界条件类型）：

【情况1：硬边界条件（Hard BC）】
│
├─ PDE损失：
│   ├─ 从位移场推导应变场：E_xx = ∂ux/∂x, ...
│   ├─ 从应变场计算应力：S_xx = E_xx*(2*mu+lambda) + ...
│   ├─ 计算平衡方程残差：∂Sxx/∂x + ∂Sxy/∂y - fx = 0
│   ├─ 计算应力一致性残差：S_xx(推导) - Sxx(预测) = 0
│   └─ ...（共5项）
│
└─ 边界条件损失：0项（边界条件通过输出变换自动满足，无需计算损失）

【情况2：软边界条件（Soft BC）】
│
├─ PDE损失：
│   ├─ 平衡方程残差：∂Sxx/∂x + ∂Sxy/∂y - fx = 0
│   ├─ 本构关系残差：S_xx(推导) - Sxx(预测) = 0
│   └─ ...（共5项）
│
└─ 边界条件损失：
    ├─ 位移边界误差：ux(预测) - ux(给定) = 0
    ├─ 应力边界误差：Syy(预测) - Syy(给定) = 0
    └─ ...（共8项）

↓

反向传播更新权重
```

### 7.1 训练点和测试点的分布

#### 7.1.1 域内训练点（num_domain=500）

**是的！** 域内训练点是在**板子内部**（不包括边界）随机选择的500个点。

**用途**：
- 计算PDE残差（平衡方程、本构关系）
- 让神经网络学习满足PDE方程

**分布**：
- 随机分布在 [0,1] × [0,1] 内部
- 不包括边界点（x=0, x=1, y=0, y=1）

#### 7.1.2 边界训练点（num_boundary=500）

**是的！** 边界训练点是在**四条边界**上随机选择的500个点。

**分布**：
- 左边界（x=0）：约125个点
- 右边界（x=1）：约125个点
- 下边界（y=0）：约125个点
- 上边界（y=1）：约125个点
- 总共500个点（可能包括角点）

**用途**：
- 计算边界条件误差
- 让神经网络学习满足边界条件

#### 7.1.3 测试点（num_test=1000）

**是的！** 测试点是在**整个板子**（包括内部和边界）随机选择的1000个点。

**用途**：
- 评估模型精度（计算L2相对误差）
- 不参与训练，只用于验证

**分布**：
- 随机分布在 [0,1] × [0,1]（包括边界）
- 用于与精确解比较

## 8. 总结

### 8.1 关键要点

1. **材料参数**：可以设置成别的值，但必须满足物理约束（>0）
2. **边界条件**：不是完全固定，上边界施加载荷；不能模拟断裂（线性弹性模型）
3. **精确解**：是根据控制方程反推出来的，用于验证
4. **应力方向**：正应力作用在垂直面上，剪应力也作用在垂直面上
5. **体积力**：代码中是反推的，实际工程中是给定的（如重力）
6. **控制方程**：是通用的，适用于所有线性弹性问题
7. **训练点**：域内500个，边界500个，测试100个
8. **模型结构**：4层隐藏层，每层40个神经元，使用tanh激活
9. **损失函数**：PDE损失（5项）+ 边界条件损失（硬边界时为0，软边界时为8项）

### 8.2 训练流程总结

1. **输入**：坐标 `[x, y]` + 边界条件 + 材料参数 + 体积力 + 几何域
2. **处理**：神经网络输出 `[ux, uy, Sxx, Syy, Sxy]`
3. **约束**：通过PDE残差和边界条件误差约束模型训练
4. **输出**：位移场和应力场

### 8.3 关键理解

- **PINN是无监督学习**：无需标签数据，仅通过物理定律约束模型训练
- **边界条件是关键**：仅靠 `[x, y]` 和损失函数无法唯一确定解，边界条件是确定唯一解的关键
- **线性弹性**：应力与应变之间是线性关系（胡克定律），适用于小变形情况
- **精确解是构造的**：用于验证PINN方法，实际工程中通常没有精确解
